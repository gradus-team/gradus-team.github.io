### Ключевые особенности версии Pro

- **Многоуровневая защита процессов:** Sysmon перехватывает создание процессов, приостанавливает их, проверяет по сигнатурам, YARA, хэшам (локальным и онлайн), MalwareBazaar, VirusTotal и в песочнице. Только после этого процесс либо завершается, либо возобновляется.
- **Интеллектуальная песочница:** изолированный запуск с блокировкой сети, глубоким анализом поведения (сетевые запросы, доступ к системе, реестру, обфускация, попытки кражи паролей и куков).
- **Антифишинг:** сочетание OpenPhish, списка вредоносных IP из GitHub и эвристики брендов с обнаружением гомоглифических атак.
- **Менеджер паролей:** AES-GCM шифрование, мастер-ключ в passwords.key.
- **Родительский контроль:** лимит времени использования ПК и веб-фильтр через hosts-файл.
- **Защита конфиденциальности:** контроль доступа к веб-камере (анализ DLL), резервное копирование куки, AMSI-мониторинг PowerShell, отключение AutoRun с USB.
- **Само-защита:** проверка целостности JAR/EXE и файла настроек.
- **Модель распространения:** разовая покупка (990₽) с пожизненными обновлениями.

### Сравнение с другими версиями

- **Free (2.75):** базовый сканер с песочницей, без YARA, Sysmon и расширенных утилит.
- **Standard (4.98):** YARA, Sysmon, антифишинг, карантин, защита камеры, бэкап — сбалансированная защита за 499₽.
- **Pro (6.80):** максимальная комплектация для пользователей, которым нужны все функции без компромиссов.
