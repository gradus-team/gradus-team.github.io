🛡️ Gradus AntiCheat — Защита от читов

Микро-модуль для скрытия настоящих значений переменных от программ вроде Cheat Engine.
Значения хранятся в искажённом виде с помощью случайных сдвигов (randint, randfloat, randstr).
Даже если злоумышленник найдёт ячейку памяти, он увидит ложное число или строку.

✨ Возможности

  • Поддержка типов: int, float, bool, str, dict, list
  • Автоматическое искажение при сохранении, восстановление при чтении
  • Проверка целостности: метод isHacked() определяет подмену
  • Мониторинг можно включать/отключать
  • Кроссплатформенность: Java, Python, JavaScript (Node.js/браузер)

🐍 Python (gradus_anti_cheat.py)

Быстрый старт

from gradus_anti_cheat import AntiCheat

ac = AntiCheat()
ac.start_monitoring()

# Добавляем здоровье (int) – в памяти будет лежать другое число!
hp = ac.add_variable("health", 100)
# Где-то в коде проверяем
if ac.is_hacked("health", 100):
    print("Читер!")
else:
    print("Всё чисто")

Все методы

МетодОписание
add_variable(name, value)Сохраняет переменную с искажением. Возвращает реальное имя (если name="VARIABLE", генерируется уникальное)
get_variable(name)Извлекает оригинальное значение
is_hacked(name, expected)Сравнивает сохранённое значение с ожидаемым. Требует включённый мониторинг
start_monitoring()Включает проверку целостности
stop_monitoring()Отключает мониторинг (is_hacked всегда false)
🔐 Секретные сдвиги
При создании объекта генерируются randint (10000–99999), randfloat (10000.0–99999.9) и randstr (случайное слово).
Они используются для искажения: int/float увеличиваются на сдвиг, bool инвертируется, к строке дописывается слово.
Таким образом, сканер памяти никогда не найдёт истинное значение.

}

🔍 Принцип работы

Вся защита строится на том, что реальное значение никогда не хранится в памяти открыто.
Например, для health = 100 в памяти будет 100 + randint (например, 50678).
Когда игра запрашивает get_variable, модуль вычитает сдвиг и возвращает 100.
Если читер попытается подменить значение напрямую (через Cheat Engine), is_hacked сравнит сохранённое искажённое значение с эталонным и обнаружит несоответствие.
