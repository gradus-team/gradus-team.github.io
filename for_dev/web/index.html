🌐 Gradus Web — Утилиты для сайтов (v2.4.0, июнь 2026)

(Ждите, до 15.06.2026 выйдет обновление 2.5 под онлайн-магазины (Shop-Update))

Единый JavaScript‑модуль для статических сайтов. Включает: кэширование, кастомное кодирование, капчу, защиту от DDoS (rate‑limiter), генераторы случайных данных, красивые всплывающие уведомления, шифрованное хранилище SecretStorage (ключ только в памяти), модуль безопасности (защита от F12, XSS и инъекций), встроенный античит с пользовательскими обработчиками, а также новые утилиты: Base64 и throttle.
Подключение: <script src="gradus-web.js"></script>

🆕 Что нового в версии 2.4 (июнь 2026):
  • SecretStorage: ключ шифрования больше не хранится в localStorage, а вычисляется заново при каждой загрузке (привязка к браузеру).
  • Base64: добавлены методы GradusWeb.toBase64 и GradusWeb.fromBase64.
  • Throttle: функция GradusWeb.throttle(fn, delay) для ограничения частоты вызовов.
  • Античит: улучшена обработка пользовательских коллбэков.
  • Исправлены уязвимости GSF‑2026‑0606‑2, GSF‑2026‑0607‑1 (см. таблицу).

✨ Возможности

  • Кэш в localStorage с TTL (время жизни)
  • Кодирование/декодирование по расширенной таблице символов (кириллица, латиница, спецсимволы)
  • Base64 кодирование/декодирование (новое в 2.4)
  • Простая математическая капча (вставка в HTML и проверка)
  • Клиентский DDoS‑протектор (ограничение частоты действий)
  • Генераторы: UUID v4, криптостойкий пароль, случайное целое
  • Тосты‑уведомления (success, error, info, warning) с автоскрытием
  • SecretStorage — шифрованное хранение конфиденциальных данных (AES‑GCM, ключ в памяти)
  • Модуль безопасности: защита от F12, XSS‑санитизация, блокировка клавиш и контекстного меню
  • Встроенный античит — защита переменных, событие onHack
  • Throttle — ограничение частоты вызова функций (новое в 2.4)

1. 📦 Кэш (GradusWeb.cache)

GradusWeb.cache.set('user', { name: 'Иван' }, 600); // на 10 минут
const user = GradusWeb.cache.get('user');           // { name: 'Иван' }
GradusWeb.cache.remove('user');
GradusWeb.cache.clear(); // очищает весь кэш Gradus
МетодОписание
set(key, value, ttlSeconds)Сохраняет значение с временем жизни (по умолчанию 3600 сек)
get(key)Возвращает значение или null, если просрочено / отсутствует
remove(key)Удаляет запись
clear()Удаляет все записи с префиксом gradus_cache_

2. 🔐 Кодирование (GradusWeb.encode / decode)

Преобразует строку по специальной таблице: каждый символ заменяется на четырёхсимвольный код _xxx.

const original = 'Привет, мир!';
const encoded = GradusWeb.encode(original);
// => "_050_018_010_003_006_020_129_000_014_010_018_132"
const decoded = GradusWeb.decode(encoded);
// => "Привет, мир!"
Таблица кодирования включает русские и латинские буквы (заглавные и строчные), цифры, пробел, знаки препинания, скобки, кавычки, решётку, обратную косую черту и даже символы перевода строки (\n, \r). Отсутствующие в таблице символы остаются без изменений.

2.1 Base64 (новое в v2.4)

const b64 = GradusWeb.toBase64('Привет!');   // "UHJp0LLQtdGC0YHQtdC80YHRgtCy0L4="
const original = GradusWeb.fromBase64(b64); // "Привет!"

3. 🤖 Капча (GradusWeb.captcha)

Математическая капча: случайный пример (сложение, вычитание, умножение).

Программное использование

const cap = GradusWeb.captcha.generate();
console.log(cap.question); // "3 + 5 = ?"
// позже проверяем ответ пользователя
if (GradusWeb.captcha.check(cap, userInput)) {
    // верно
}

Готовый HTML‑виджет

<div id="captcha-box"></div>
<button onclick="checkCaptcha()">Проверить</button>

<script>
GradusWeb.captcha.render('captcha-box');
function checkCaptcha() {
    if (GradusWeb.captcha.verify('captcha-box')) {
        GradusWeb.notify.success('Проверка пройдена');
    } else {
        GradusWeb.notify.error('Неверный ответ');
    }
}
</script>

4. 🛡️ DDoS Protection (GradusWeb.ddos)

Клиентский ограничитель частоты действий (rate limiter).

// Разрешить не более 3 кликов за 10 секунд для действия 'submit_btn'
document.getElementById('btn').addEventListener('click', () => {
    if (GradusWeb.ddos.isAllowed('submit_btn', 3, 10)) {
        // выполнить действие
    } else {
        GradusWeb.notify.warning('Слишком много запросов. Подождите.');
    }
});
МетодОписание
isAllowed(id, maxRequests, intervalSeconds)Возвращает true, если действие разрешено
reset(id)Сбрасывает счётчик для указанного ID
clear()Сбрасывает все ограничения

7. 🔒 SecretStorage (шифрованное хранилище, v2.4)

Хранит данные в localStorage в зашифрованном виде (AES‑GCM). Ключ шифрования теперь только в памяти — он не сохраняется нигде, а вычисляется заново при каждой загрузке страницы на основе отпечатка браузера (User‑Agent, язык, разрешение экрана и т.д.). Расшифровать данные можно только в том же браузере. 

// Сохранить (асинхронно)
await GradusWeb.secretStorage.set('api_key', 'sk_live_1234567890');

// Прочитать
const key = await GradusWeb.secretStorage.get('api_key');

// Удалить
await GradusWeb.secretStorage.remove('api_key');

// Полностью очистить все секреты (удобно при обнаружении F12)
await GradusWeb.secretStorage.clear();

Где хранить секреты? Вы можете использовать только локальное шифрование (данные в localStorage), либо получать секреты с защищённого сервера через прокси (например, {server_get:https://your-proxy.com/secret}). Рекомендуется комбинировать оба подхода для максимальной безопасности.

⚠️ Важно: Абсолютной защиты на клиенте не существует. Для критичных секретов всегда предпочитайте серверный прокси.
МетодОписание
set(name, value)Асинхронно сохраняет значение в зашифрованном виде
get(name)Асинхронно возвращает расшифрованное значение (или null)
remove(name)Удаляет запись
clear()Удаляет все секреты

8. 🛡️ Модуль безопасности (GradusWeb.security)

Защита от DevTools (F12)

Включает несколько методов детекта открытой консоли: проверка размера окна, зацикленный debugger, очистка консоли. При обнаружении вызывает пользовательский callback. Можно указать removeScripts: true для удаления всех тегов <script> со страницы, а также skipMobile: true для пропуска мобильных устройств.

GradusWeb.security.enableDevToolsProtection(() => {
    alert('DevTools открыты!');
    // удаляем секреты, очищаем кэш, перезагружаем страницу...
}, { removeScripts: true, skipMobile: true });

Также автоматически блокируются клавиши F12, Ctrl+Shift+I, Ctrl+U и контекстное меню (правый клик).

Защита от XSS и инъекций

const safe = GradusWeb.security.sanitizeHTML('');
// safe = "<script>alert("xss")</script>"
const clean = GradusWeb.security.sanitizeScript(unsafeString);
МетодОписание
enableDevToolsProtection(callback, options?)Включает слежение за DevTools с дополнительными настройками
disableDevToolsProtection()Отключает слежение
sanitizeHTML(str)Возвращает строку, безопасную для вставки в HTML
sanitizeScript(str)Удаляет теги <script>

9. 🎮 Встроенный античит (GradusWeb.antiCheat)

Защищает переменные от изменений через Cheat Engine и подобные утилиты. Можно зарегистрировать пользовательский обработчик, который срабатывает при обнаружении взлома. 

// Создание экземпляра с обработчиком
const ac = GradusWeb.antiCheat.createInstance((name, value, reason) => {
    console.warn(`Обнаружен взлом переменной "${name}"! Причина: ${reason}`);
    // Здесь можно отправить лог на сервер, заблокировать аккаунт и т.д.
});
ac.startMonitoring();

// Добавление защищённой переменной
const healthId = ac.addVariable('health', 100);

// Проверка в игровом цикле
setInterval(() => {
    if (ac.isHacked(healthId, 100)) {
        GradusWeb.notify.error('Обнаружена попытка взлома здоровья!');
    }
}, 5000);
МетодОписание
createInstance(onHackCallback?)Создаёт экземпляр античита с коллбэком взлома
startMonitoring()Включает проверку
stopMonitoring()Останавливает проверку
addVariable(name, value)Добавляет защищённую переменную (возвращает её имя)
getVariable(name)Возвращает оригинальное значение (расшифрованное)
isHacked(name, expectedValue)Проверяет, не подменено ли значение (возвращает true при взломе)
onHack(callback)Регистрирует обработчик взлома (если не был передан в createInstance)

10. ⏱️ Throttle (новое в v2.4)

Ограничивает частоту вызова функции: она будет выполняться не чаще, чем раз в указанный интервал.

// Обработчик прокрутки, который срабатывает не чаще раза в 200 мс
window.addEventListener('scroll', GradusWeb.throttle(() => {
    console.log('Прокрутка!');
}, 200));
