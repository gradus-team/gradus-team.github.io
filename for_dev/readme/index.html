🛡️ GradusCore v2 — Антивирусное ядро

Кроссплатформенное лёгкое ядро для сканирования файлов, проверки URL, изолированного анализа (песочница), обнаружения руткитов и скрытого запуска. Реализовано на Java, Python и JavaScript (Node.js).
Все сигнатуры встроены, внешние файлы не требуются. Идеально для телеграм‑ботов, веб‑приложений, систем автоматической проверки.

🚀 Новые возможности v2

  • Кроссплатформенность — Windows, Linux, macOS. Автоопределение ОС для специфичных проверок.
  • Песочница — статический анализ любых файлов + динамический запуск с таймаутом (Windows) и опциональный strace‑анализ (Linux).
  • Проверка URL — бесплатная онлайн‑проверка на фишинг через OpenPhish.
  • Поиск руткитов — Windows (tasklist, sc query), Linux (скрытые процессы, модули ядра), macOS (kextstat).
  • Обнаружение скрытого запуска с правами администратора/root из подозрительных папок.
  • Кастомное сканирование — выборочное включение нужных методов (сигнатуры, песочница, руткиты, скрытый запуск).
  • Сканирование текста/буфера — для интеграции в ботов (Telegram, Discord).
  • Автоматическое создание временных папок — не требует ручной настройки, очищается при завершении.

📦 Поддерживаемые команды (CLI)

# Java
java -jar GradusCore.jar scan <путь>
java -jar GradusCore.jar url-scan <url>
java -jar GradusCore.jar sandbox-scan <файл>
java -jar GradusCore.jar rootkit
java -jar GradusCore.jar stealth
java -jar GradusCore.jar custom-scan [--signatures] [--sandbox] [--rootkit] [--stealth] <путь>
java -jar GradusCore.jar docs

# Python / Node.js — аналогично
python graduscore.py scan <путь>
node graduscore.js url-scan <url>
ℹ️ Примечание: Команды rootkit, stealth и динамическая часть песочницы требуют соответствующих привилегий (администратор/root) и могут работать не во всех окружениях (например, на хостингах без доступа к системным вызовам). Статический анализ, сигнатуры и проверка URL работают всегда.

⚙️ Настройки (Settings)

Параметр Тип По умолчанию Описание
notifications boolean false Вывод логов в консоль
useSignatures boolean true Сигнатурный анализ
useMalwareBazaar boolean false Проверка SHA‑256 через MalwareBazaar
useSandbox boolean false Анализ в песочнице (статический + динамический при возможности)
checkRootkits boolean false Поиск скрытых процессов/драйверов
checkStealth boolean false Проверка скрытого запуска с правами администратора
useAdvancedSandbox boolean false На Linux включает strace‑анализ (требуется установленный strace)

☕ Java

Использование как библиотека

import graduscore.GradusCore;
import graduscore.GradusCore.Settings;

Settings s = new Settings();
s.notifications = true;
s.useSignatures = true;
s.useSandbox = true;          // песочница
s.checkRootkits = true;       // поиск руткитов

GradusCore core = new GradusCore(s);

// Сканирование файла/папки
int threat = core.scan(new File("путь"));
System.out.println("Угроза: " + threat + "%");

// Проверка URL
String result = core.scanURL("http://example.com");
System.out.println(result);   // SAFE / PHISHING / SUSPICIOUS

// Песочница для файла
int sandboxThreat = core.sandboxScan(new File("test.exe"));

// Системные проверки
boolean rootkitFound = core.rootkitScan();
boolean stealth = core.stealthLaunchDetected();

// Кастомный скан
Settings custom = new Settings();
custom.useSignatures = true;
custom.useSandbox = true;
custom.checkRootkits = true;
int res = core.customScan(new File("папка"), custom);
// res == -1 означает системную угрозу (руткит/скрытый запуск)

🐍 Python

Использование как библиотека

from graduscore import GradusCore, Settings
from pathlib import Path

settings = Settings(
    notifications=True,
    use_signatures=True,
    use_sandbox=True
)
core = GradusCore(settings)

# Сканирование файла/папки
threat = core.scan(Path("путь"))

# Сканирование байтов (например, из Telegram)
threat = core.scan_bytes(b"file content", "file.exe")

# Сканирование текста
threat = core.scan_text(code_text, "script.bat")

# Проверка URL
result = core.scan_url("http://example.com")

# Песочница
sandbox_threat = core.sandbox_scan(Path("test.exe"))

# Системные проверки
rootkit_found = core.rootkit_scan()
stealth_detected = core.stealth_launch_detected()

# Кастомный скан
custom = Settings(use_signatures=True, use_sandbox=True, check_rootkits=True)
res = core.custom_scan(Path("путь"), custom)  # -1 = системная угроза

🤖 Пример для aiogram (Telegram)

from aiogram import Bot, Dispatcher, types
from graduscore import GradusCore, Settings
import io

bot = Bot(token="TOKEN")
dp = Dispatcher(bot)
core = GradusCore(Settings(notifications=False))

@dp.message_handler(content_types=types.ContentType.DOCUMENT)
async def handle_document(message: types.Message):
    file = io.BytesIO()
    await message.document.download(destination_file=file)
    threat = core.scan_bytes(file.getvalue(), message.document.file_name)
    await message.reply(f"Уровень угрозы: {threat}%")

🟩 JavaScript / Node.js

Использование как библиотека

const { GradusCore, Settings } = require('./graduscore.js');
const fs = require('fs');

const settings = new Settings({
    notifications: true,
    useSignatures: true,
    useSandbox: true
});
const core = new GradusCore(settings);

// Синхронное сканирование файла/папки (без MalwareBazaar)
const threat = core.scan('/путь/к/файлу');

// Сканирование буфера
const buffer = fs.readFileSync('file.exe');
const threat = core.scanBuffer(buffer, 'file.exe');

// Проверка URL (асинхронно)
core.scanURL('http://example.com').then(result => console.log(result));

// Песочница
const sandThreat = core.sandboxScan('test.exe');

// Системные проверки
const rootkit = core.rootkitScan();
const stealth = core.stealthLaunchDetected();

// Кастомный скан
const custom = new Settings({ useSignatures: true, useSandbox: true });
const res = core.customScan('/папка', custom);  // -1 = системная угроза

🤖 Пример для node-telegram-bot-api

const TelegramBot = require('node-telegram-bot-api');
const { GradusCore, Settings } = require('./graduscore.js');

const bot = new TelegramBot('TOKEN', { polling: true });

bot.on('document', async (msg) => {

    const file = await bot.getFile(fileId);

});

🔍 Принцип работы

Ядро содержит встроенные сигнатуры для разных типов файлов. При сканировании определяется расширение и применяются соответствующие регулярные выражения. Для исполняемых файлов (PE) дополнительно ищутся подозрительные строки в бинарном коде. При включённой опции useMalwareBazaar вычисляется SHA‑256 и отправляется запрос к публичному API.

Песочница выполняет статический анализ (поиск опасных паттернов в байтах), а на Windows ещё и запускает файл с ограничением по времени и блокировкой сети. На Linux можно включить strace‑анализ. Системные проверки используют команды ОС и файлы в /proc (на Linux).
