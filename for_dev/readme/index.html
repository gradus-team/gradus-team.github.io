🛡️ GradusCore — Антивирусное ядро

Лёгкое сигнатурное ядро для сканирования файлов и папок, написанное на Java, Python и JavaScript (Node.js).
Не требует внешних файлов — все сигнатуры встроены в код.
Подходит для встраивания в приложения, ботов, системы автоматической проверки.

✨ Возможности

  • Сигнатурный анализ (bat, js, exe, url, py, rootkits и др.)
  • Опциональная проверка через MalwareBazaar по SHA‑256
  • Сканирование файлов, папок, буферов в памяти и текста
  • Возвращает максимальный процент угрозы (0–100)
  • Никаких внешних зависимостей (кроме стандартной библиотеки)

☕ Java (GradusCore.java)

Командная строка

<>java -jar GradusCore.jar <путь к файлу или папке>
java -jar GradusCore.jar docs

Как библиотека

import graduscore.GradusCore;
import graduscore.GradusCore.Settings;

Settings settings = new Settings();
settings.useSignatures = true;      // по умолчанию true
settings.useMalwareBazaar = false;  // по умолчанию false

GradusCore core = new GradusCore(settings);
int threat = core.scan(new File("C:/test"));
System.out.println("Угроза: " + threat + "%");

🐍 Python (graduscore_py.py)

Установка не требуется. Достаточно скопировать файл graduscore_py.py в проект или бот.

Командная строка

python graduscore_py.py <путь к файлу или папке>
python graduscore_py.py docs

Как библиотека

from graduscore_py import GradusCore, Settings

settings = Settings()
settings.use_signatures = True
settings.use_malwarebazaar = False

core = GradusCore(settings)

# Сканирование по пути
threat = core.scan("/путь/к/файлу.exe")

# Сканирование байтов (например, из Telegram-бота)
file_bytes = ...  # получили от пользователя
threat = core.scan_bytes(file_bytes, "file.exe")

# Сканирование текста (без сохранения файла)
text = core.get_text_from_file("script.bat")
threat = core.scan_text(text, "script.bat")
🤖 Интеграция в Telegram-бота (aiogram 2.x)
Ниже показано, как принимать файлы и текстовые сообщения от пользователей. 
from aiogram import Bot, Dispatcher, types
from graduscore_py import GradusCore, Settings

bot = Bot(token="YOUR_TOKEN")
dp = Dispatcher(bot)
core = GradusCore(Settings())
core.settings.notifications = False

@dp.message_handler(content_types=types.ContentType.DOCUMENT)
async def handle_document(message: types.Message):
    document = message.document
    file = await bot.get_file(document.file_id)
    file_bytes = await file.download_as_bytes()
    threat = core.scan_bytes(file_bytes, document.file_name)
    await message.reply(f"Уровень угрозы: {threat}%")

@dp.message_handler(content_types=types.ContentType.TEXT)
async def handle_text(message: types.Message):
    text = message.text
    threat = core.scan_text(text, "script.bat")
    await message.reply(f"Уровень угрозы: {threat}%")

🟩 JavaScript / Node.js (graduscore_js.js)

Установка не требуется. Подключается как обычный модуль.

Командная строка

node graduscore_js.js <путь к файлу или папке>
node graduscore_js.js docs

Как библиотека

const { GradusCore, Settings } = require('./graduscore_js.js');

const settings = new Settings();
settings.useSignatures = true;
settings.useMalwareBazaar = false;

const core = new GradusCore(settings);

// Синхронное сканирование (без MalwareBazaar)
const threat = core.scan('/путь/к/файлу.exe');

// Сканирование буфера (например, из бота)
const buffer = fs.readFileSync('file.exe');
const threat = core.scanBuffer(buffer, 'file.exe');

// Асинхронное с проверкой MalwareBazaar
(async () => {
    const threat = await core.scanBufferAsync(buffer, 'file.exe');
    console.log(`Угроза: ${threat}%`);
})();

// Сканирование текста
const threat = core.scanText('some malicious code', 'script.bat');

🤖 Пример для node-telegram-bot-api

const TelegramBot = require('node-telegram-bot-api');
const { GradusCore, Settings } = require('./graduscore_js.js');

const bot = new TelegramBot('YOUR_TOKEN', { polling: true });
const core = new GradusCore(new Settings());

bot.on('document', async (msg) => {
    const fileId = msg.document.file_id;
    const file = await bot.getFile(fileId);
    const buffer = await bot.downloadFile(file.file_path, './');
    const threat = core.scanBuffer(buffer, msg.document.file_name);
    bot.sendMessage(msg.chat.id, `Уровень угрозы: ${threat}%`);
});

🔍 Принцип работы

Ядро содержит встроенные наборы сигнатур для различных типов файлов. При сканировании определяется расширение файла и применяются соответствующие регулярные выражения. Для исполняемых файлов (PE) дополнительно ищутся подозрительные строки в бинарном коде. При включённой опции useMalwareBazaar вычисляется SHA‑256 и отправляется запрос к публичному API.
