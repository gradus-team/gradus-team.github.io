📚 Gradus RayCast ENGINE (1.0)
Полноценный движок на Python основанный на Ray Casting с авторскими технологиями Light Tracing, Physics-S (в 1.0 это просто коллизии), OBJ-Converter (конвертирует .obj в 64 спрайта 512x512 пикселей что создает ощущение реального .obj внутри рейкастинг-мира), также там присутствует самописное API носящее имя MicroAPI для взаимодействия с миром в коде динамично, а также есть наложение видео поверх игры, звук, блоки-триггеры для которых надо писать код, порталы (id=9, переносит на указанный уровень), смотрите все остальное в документации.
