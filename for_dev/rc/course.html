Это не курс по Markdown и не набор абстрактных задач. Каждый урок заканчивается изменением настоящей игры в GradusRC Studio. Сквозной проект — атмосферный FPS-квест «Последний маяк».

Схемы используют реальные типы узлов из каталога Visual Programming Gradus: названия блоков, входы/выходы и связи EXEC. Это учебные схемы структуры графа, а не скриншоты интерфейса. Доступность исполнения зависит от конкретного runtime и поддерживаемого набора узлов.

ДОМАШНЯЯ РАБОТА В ИГРЕ

В Studio создай проект «Последний маяк». Собери комнату с коридором, двумя боковыми помещениями и финальной дверью. Добавь spawn point, свет и хотя бы два материала стен. Запусти игру и пройди уровень от старта до двери.

Как проверить результат

Игрок появляется в нужной точке, стены блокируют движение, карта загружается без ошибок.

ДОМАШНЯЯ РАБОТА В ИГРЕ

Как проверить результат

Проверяются обе ветки: без ключа отказ; с ключом дверь открывается. Повторное взаимодействие не ломает состояние.
