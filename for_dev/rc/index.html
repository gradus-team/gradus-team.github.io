📖 Введение

Gradus RC — это библиотека для создания псевдо-3D игр с рейкастингом на Python + Pygame. Версия 1.1 включает значительные оптимизации, объёмный звук, улучшенный конвертер OBJ, поддержку цветных граней через .gbj, а также готовые заготовки меню и игры.

📦 Установка

pip install pygame trimesh numpy imageio imageio-ffmpeg

Обязательные зависимости: pygame. Для .obj моделей нужны trimesh и numpy. Для видео — imageio и imageio-ffmpeg.

Скопируйте папку gradus_rc/ в корень проекта.

🧩 Архитектура

  • Engine – главный класс. Создаётся один раз.
  • Player – положение, угол поворота, скорость.
  • RayCaster – выполняет рейкастинг (оптимизирован: предрасчёт углов, асинхронный режим).
  • LightTracer – управляет освещением (ускорен расчёт).
  • SpriteManager – хранит и рисует билборды и модели-спрайты.
  • SoundManager – загружает и воспроизводит звуки.
  • Sound3D – объёмный звук с позиционированием.
  • EffectsManager – полноэкранные пост‑эффекты (зернистость, помехи, глюки, VHS).
  • MicroAPI – тонкое управление объектами во время игры (доступен через engine.api).

🗺️ Формат карты (уровня)

Карта — это многострочная строка с секциями. Все ключи регистронезависимы (парсер приводит к нижнему регистру).

Секции

СекцияОписаниеПример
[COLLISION]Основная карта (стены, проходимость)1 1 1
1 0 1
[FLOOR_COLOR=RRGGBB]Цвет пола (HEX без #)FLOOR_COLOR=444444
[CEILING_COLOR=RRGGBB]Цвет потолкаCEILING_COLOR=888888
[SPAWN=x,y]Спавн игрока (в клетках)SPAWN=0.5,0.5
[AMBIENT=0.0..1.0]Базовая освещённостьAMBIENT=0.03
[USE_LT=0/1]Освещение пола/потолкаUSE_LT=1
[LIGHTS=x,y,intensity,radius; ...]Статические источники светаLIGHTS=2.5,2.5,0.4,200
[BILBOARDS=x,y,key; ...]Спрайты (из папки textures/)BILBOARDS=3.5,2.5,tree

Клетки в [COLLISION] разделяются пробелами. Каждая клетка может содержать теги в угловых скобках:

1<material:brick,height:0.9,color:FFAA00,isvisible:0>
6<path:models/cube.obj,roty:45,rotx:10,scale:2.0,color:FF0000,isvisible:1>
7<type:door,id:door1,link:key1>
8<id:1>
9<level:1>

🧱 ID клеток (в [COLLISION])

IDТипОписаниеДопустимые теги (ключи в нижнем регистре)
0ПустотаПроходимо, ничего не отображается—
1Стена (бетон)Обычная стена, материал по умолчанию concretematerial, color, height, texture, isvisible (alpha не поддерживается)
2Стена (стекло)Визуально – стекло (прозрачность отключена для производительности). Используйте isvisible:0 для невидимости.те же, что у ID=1
3Кирпичmaterial=brickте же
4Деревоmaterial=woodте же
5Металлmaterial=metalте же
63D-модельЗагружает .obj (или .gbj) и рендерит в спрайтыpath, rotx, roty, rotz, scale, color, anim, anim_speed, isvisible
7Дверь/КлючСистема ключ-дверь. Видимость спрайта управляется через api.set_sprite_visible(sprite_key, visible).type, id, link, texture, height, material
8ТриггерВызывает on_trigger(cell). Всегда невидим.id

Важно:

  • isvisible (или isVisible) работает для ID=1–6. Для ID=7 видимость управляется через API. ID=8 и 9 всегда невидимы.
  • alpha не поддерживается из-за высоких нагрузок на FPS. Используйте isvisible:0 для скрытия.
  • height работает только для стен (ID 1–5) и может снижать FPS при значениях < 1.0. Используйте с осторожностью.

🧱 Доступные материалы (для тега material)

  • brick – кирпич (красноватый)
  • concrete – бетон (серый)
  • glass – стекло (прозрачность отключена, но цвет голубоватый)
  • wood – дерево
  • granite – гранит
  • earth – земля
  • metal – металл
  • plaster – штукатурка
  • marble – мрамор
  • obsidian – обсидиан
  • gold, silver, copper
  • sand, snow, water, lava

🗝️ Двери и ключи (ID=7)

Клетка с ID=7 может быть либо дверью (type:door), либо ключом (type:key).

  • Дверь – непроходима, пока не открыта ключом. Визуально — спрайт двери (по умолчанию door.png).
  • Ключ – проходимый спрайт (по умолчанию key.png). При подборе автоматически открывает связанную дверь.

Связь: через тег link (указывается id двери у ключа и наоборот).

7<type:door,id:door1,link:key1>
7<type:key,id:key1,link:door1>

Управление через MicroAPI:

api.open_door('door1')
api.close_door('door1')
api.collect_key('key1')
api.has_key('key1')

Видимость спрайта двери/ключа управляется через api.set_sprite_visible(sprite_key, True/False).

🎯 Триггеры (ID=8)

При касании клетки с ID=8 вызывается метод on_trigger(cell). Чтобы триггер сработал только один раз, используйте:

self.deactivate_trigger(('id', trigger_id))

Триггеры всегда невидимы и не имеют коллизии.

🌀 Порталы (ID=9)

Клетка с ID=9 и тегом level мгновенно переносит игрока на указанный уровень (индекс в списке levels).

9<level:1>

Порталы всегда невидимы и не имеют коллизии.

📦 3D-модели (ID=6)

Параметры:

  • path – путь к .obj или .gbj (обязательно).
  • rotx, roty, rotz – повороты модели в градусах.
  • scale – масштаб (1.0 ≈ размер клетки).
  • color – цвет модели (HEX, например FF0000).
  • anim – список моделей для анимации (через запятую).
  • anim_speed – скорость смены кадров (секунд на кадр, по умолчанию 0.5).
  • isvisible – 0/1 (по умолчанию 1).

При первом запуске генерируются спрайты (64 кадра) и сохраняются в папку cache/. Кэш учитывает все параметры, поэтому при изменении цвета или поворота спрайты будут пересозданы автоматически после удаления старой папки cache.

6<path:models/cube.obj,roty:45,scale:2.0,color:FF0000,isvisible:1>
6<path:models/box.obj,anim:models/box_open1.obj,models/box_open2.obj,anim_speed:0.3>

🎨 Формат .gbj (цветные грани)

Для поддержки цвета отдельных граней используется расширение .gbj. Это тот же OBJ, но в строках граней может быть указан цвет в HEX после индексов вершин.

Пример строки грани с цветом:

f 1 2 3 FF8800

Если цвет не указан, используется общий color модели. При экспорте из вашего будущего мини-блендера вы сможете задавать цвета.

Использование:

6<path:models/colored_model.gbj,scale:1.0>

Цвет граней автоматически подхватывается при рендеринге спрайтов.

🔄 Анимация .obj

При указании anim генерируются спрайты для каждой модели в списке, и они последовательно сменяются с заданной скоростью.

💡 Освещение

  • [AMBIENT] – базовая яркость (0..1).
  • [LIGHTS] – статические источники (x,y,intensity,radius).
  • Фонарик игрока управляется через engine.light_tracer.update_player_light(...) или через api.set_player_light(radius, intensity, color).

Пример добавления источника через код:

from gradus_rc import LightSource
engine.light_tracer.add_source(LightSource(300, 300, 250, 0.6, (255,200,100)))

🖼️ Билборды (спрайты)

Спрайты всегда повёрнуты к игроку. Создаются через класс Sprite и добавляются в engine.

tex = load_image('tree', 'textures/tree.png', size=(64,64))
sprite = Sprite(x=200, y=300, texture=tex, key='tree')
engine.add_sprite(sprite)
engine.set_sprite_visible('tree', False)
engine.set_sprite_position('tree', 100, 200)

🎬 Видео-оверлей

Воспроизведение видео на экране с помощью engine.play_video().

# Полноэкранное с циклом
engine.play_video('intro.mp4', mode="full", loop=True)
# В углу (25% экрана)
engine.play_video('intro.mp4', mode="angle")
# Произвольный размер и позиция
engine.play_video('intro.mp4', mode="custom", x=100, y=100, width=400, height=300)
# С удалением цветового ключа (хромакей) для прозрачности
engine.play_video('intro.mp4', mode="full", alpha_chroma=True, chroma_color=(0,255,0))
engine.stop_video()

🖱️ Управление мышью

Передайте mouse_sensitivity в конструктор Engine и вызывайте engine.handle_mouse(event) в цикле событий. Захват курсора – правая кнопка мыши.

🔧 MicroAPI

Доступен через engine.api. Позволяет управлять объектами во время игры.

Стены и клетки

api.get_cell(x, y)                # возвращает ячейку (словарь)
api.set_cell_property(x, y, key, value)   # key в нижнем регистре
api.set_cell_base_id(x, y, new_id)
api.set_cell_visible(x, y, visible)       # isvisible
api.set_cell_collision(x, y, collision)   # addcollision

Игрок

api.set_player_position(x, y)
api.set_player_angle(angle)
api.set_player_speed(speed)
api.set_player_rot_speed(rot_speed)

Свет

api.get_light_sources()
api.add_light(x, y, radius, intensity, color)
api.remove_light(index)
api.set_ambient(value)
api.set_player_light(radius, intensity, color)

Спрайты

api.get_sprites()
api.set_sprite_position(key, x, y)
api.set_sprite_visible(key, visible)
api.remove_sprite(key)

Двери и ключи

api.open_door(door_id)
api.close_door(door_id)
api.is_door_open(door_id)
api.collect_key(key_id)
api.has_key(key_id)

Модели (ID=6)

api.get_model(model_key)                 # вернуть ModelSprite по ключу
api.set_model_position(model_key, x, y)
api.set_model_rotation_x(model_key, rot_deg)
api.set_model_rotation_y(model_key, rot_deg)
api.set_model_rotation_z(model_key, rot_deg)
api.set_model_visible(model_key, visible)

Эффекты (EffectsManager)

api.set_effect(effect_type, alpha=255, intensity=0.5)   # включить эффект
api.clear_effect()                                      # выключить

3D-звук (Sound3D)

# Воспроизвести звук в мировых координатах (пикселях)
api.play_sound_3d_world('sound_key', x=300, y=200)

# В тайловых координатах (умножается на tile_size)
api.play_sound_3d_tile('sound_key', tile_x=5, tile_y=3)

# Относительно игрока с учётом поворота камеры (offset_x – влево/вправо, offset_y – вперёд/назад)
api.play_sound_3d_player_camera('sound_key', offset_x=-1.0, offset_y=0.5)

# Относительно игрока без учёта поворота
api.play_sound_3d_player('sound_key', offset_x=10, offset_y=0)

# Все методы возвращают объект Sound3D для управления (stop, изменение громкости)

🔊 Звук и Sound3D

Обычное воспроизведение:

engine.sound_manager.load_all({'scream':'sounds/scream.wav'})
engine.play_sound('scream')
engine.sound_manager.stop_sound('scream')

Объёмный звук (Sound3D)

Движок поддерживает позиционирование звука в 3D. Звук затухает с расстоянием, панорамируется в зависимости от направления камеры, приглушается стенами. Для использования загрузите звук как обычно, затем вызовите один из методов play_sound_3d_*.

Пример использования:

# Загрузили звук
engine.sound_manager.load_all({'music': 'music.wav'})

# Воспроизводим звук, источник находится в мировых координатах (500, 300)
snd = engine.play_sound_3d_world('music', world_x=500, world_y=300)

# Чуть позже можно остановить
snd.stop()

Параметры:

  • max_distance – максимальная слышимость (в пикселях). По умолчанию 500.
  • doppler_factor – коэффициент эффекта Доплера (пока минимальный).

Все методы автоматически обновляют громкость и панораму каждый кадр, пока звук играет.

✨ Полноэкранные эффекты (EffectsManager)

Движок включает встроенный менеджер пост‑эффектов для создания атмосферы VHS, помех, зернистости и глюков. Эффекты накладываются на весь экран после отрисовки сцены и могут быть включены/выключены в любой момент.

Доступные эффекты

  • 'noise' – цветная зернистость по всему экрану.
  • 'static' – вертикальные полупрозрачные полосы (VHS‑помехи).
  • 'glitch' – тонкие горизонтальные цветные полосы (цветовые глюки).
  • 'vhs' – комбинация всех трёх эффектов сразу.

Управление эффектами

Включение через MicroAPI:

engine.api.set_effect('vhs', alpha=180, intensity=0.7)

Или напрямую через менеджер:

engine.effects_manager.set_effect('glitch', alpha=200, intensity=0.5)

Выключение:

engine.api.clear_effect()
# или
engine.effects_manager.clear_effect()

Параметры:

  • alpha – общая прозрачность эффекта (0..255). По умолчанию 255.
  • intensity – сила эффекта (0.0..1.0). По умолчанию 0.5. Чем выше, тем больше элементов (точек, полос и т.д.).

Пример использования в скрипте:

# Включить VHS на 3 секунды
engine.api.set_effect('vhs', alpha=180, intensity=0.7)
pygame.time.delay(3000)
engine.api.clear_effect()
⚡ Производительность: слои эффектов обновляются с интервалом 0.3 секунды, чтобы не снижать FPS. Вы можете изменить интервал в EffectsManager._update_interval.

🎮 Заготовки (Menu и Game) – подробная настройка

В папке gradus_rc/examples/ есть два класса-заготовки: MenuExample и GameExample. Они помогут быстро создать меню и игровой цикл.

📋 MenuExample – настройка меню

Теперь меню не требует движок при создании. Вы передаёте только размеры и опции.

from gradus_rc.examples import MenuExample

menu = MenuExample(
    width=800, height=600,
    background_image='menu_bg.jpg',   # фон (опционально)
    button_align='center'             # 'center', 'left', 'right'
)

Что можно настроить:

  • background_image – путь к фоновой картинке (полноэкранная).
  • button_align – выравнивание кнопок: 'center', 'left', 'right'.
  • about_text – текст для раздела "О игре" (если есть).

В меню автоматически создаются кнопки: Играть, Настройки, Выход.

В настройках можно менять:

  • Графику: Lite, Medium, High, Ultra (количество лучей).
  • FOV (60, 75, 90).
  • FPS (30, 60, 120).
  • Render Scale (Off, 2x, 3x, 4x).
  • MCFI – вкл/выкл (frame blending).
  • Async Raycast – вкл/выкл.
  • Sensitivity – чувствительность мыши (player_rot_speed) от 0.1 до 10.
  • Show FPS – показывать счётчик FPS в углу.

При нажатии "Играть" меню возвращает словарь настроек, который можно передать в GameExample.

🎮 GameExample – настройка игры

Игровой цикл принимает класс движка (не экземпляр) и все параметры, включая настройки из меню.

from gradus_rc.examples import GameExample
from gradus_rc import Engine

class MyEngine(Engine):
    def on_trigger(self, cell):
        print("Триггер!")

game = GameExample(
    engine_class=MyEngine,       # ваш класс движка
    levels=[LEVEL1, LEVEL2],
    current_level=0,
    width=800, height=600,
    player_speed=48.0,           # скорость игрока задаётся в коде
    **settings                   # все настройки из меню
)
game.run()

Параметры:

  • engine_class – класс вашего движка (наследник Engine).
  • levels – список строк-карт.
  • current_level – стартовый уровень.
  • width, height – размеры окна.
  • fullscreen – True/False (по умолчанию False).
  • player_speed – скорость передвижения игрока.
  • Остальные параметры (rays, fov, fps, render_scale, async_raycast, mcfi, show_fps, player_rot_speed) передаются через **settings.

Вы можете переопределить on_trigger, on_key_pickup, on_door_blocked в своём классе движка.

🔁 Полный цикл с меню и игрой

import pygame
from gradus_rc.examples import MenuExample, GameExample
from gradus_rc import Engine

class MyEngine(Engine):
    pass

def main():
    pygame.init()
    WIDTH, HEIGHT = 800, 600
    screen = pygame.display.set_mode((WIDTH, HEIGHT))

    menu = MenuExample(width=WIDTH, height=HEIGHT, button_align='left')
    settings = None

    while menu.running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                menu.running = False
            res = menu.handle_event(event)
            if isinstance(res, dict):
                settings = res
                break
        menu.render(screen)
        pygame.display.flip()

    if settings:
        game = GameExample(
            engine_class=MyEngine,
            levels=[LEVEL1, LEVEL2],
            current_level=0,
            width=WIDTH,
            height=HEIGHT,
            player_speed=48.0,
            **settings
        )
        game.run()

if __name__ == "__main__":
    main()

⏳ Экран загрузки

При старте движок показывает водяной знак (из material/images/watermark.png) и прогресс кэширования моделей. Вызов engine.prepare_models(screen) автоматически показывает загрузку и держит экран минимум 3 секунды.

Вы можете изменить водяной знак, заменив файл gradus_rc/material/images/watermark.png.

⚡ Оптимизация

Движок версии 1.1 включает несколько важных оптимизаций, которые в сумме дают прирост до 30 раз.

  • Кэширование столбцов текстур – устраняет избыточные операции чтения пикселей для каждой стены.
  • Предрасчёт углов рейкастинга – убирает вызовы тригонометрии из горячего цикла.
  • Асинхронный рейкастинг – расчёт лучей в фоновом потоке, чтобы не блокировать отрисовку.
  • Масштабирование рендера (Render Scale) – рендер в уменьшенном разрешении с последующим масштабированием, что резко снижает нагрузку.
  • MCFI (Frame Blending) – визуальное сглаживание движения путём смешивания кадров (не повышает реальный FPS, но улучшает восприятие).
  • Оптимизированное освещение – замена дорогих операций на квадраты расстояний.

Дополнительные советы:

  • Уменьшите rays для слабых устройств (например, 200–300 лучей обычно достаточно).
  • Используйте render_scale=2 или 3, если нужно поднять FPS.
  • Избегайте alpha и частично прозрачных стен.
  • Для статичных сцен можно отключить обновление освещения.

class MyEngine(Engine):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.sound_manager.load_all({'scream': 'scream.wav'})
        self.CLEAR_EVENT = pygame.USEREVENT + 10

    def on_trigger(self, cell):
        trigger_id = cell.get('properties', {}).get('id', 0)
        if trigger_id == 1:
            self.deactivate_trigger(('id', trigger_id))
            self.set_overlay('scary_face.jfif', 200)
            self.play_sound('scream')
            pygame.time.set_timer(self.CLEAR_EVENT, 1000)

    def handle_event(self, event):
        if event.type == self.CLEAR_EVENT:
            self.clear_overlay()
            self.sound_manager.stop_sound('scream')
            pygame.time.set_timer(self.CLEAR_EVENT, 0)

def main():
    pygame.init()
    WIDTH, HEIGHT = 800, 600
    screen = pygame.display.set_mode((WIDTH, HEIGHT))
    pygame.display.set_caption("Gradus RC Final")
    clock = pygame.time.Clock()

    engine = MyEngine(
        levels=[LEVEL1, LEVEL2],
        current_level=0,
        width=WIDTH,
        height=HEIGHT,
        fov=60,
        rays=800,
        tile_size=64,
        max_depth=1000,
        proj_coeff=20000,
        player_speed=48.0,
        player_rot_speed=3.0,
        mouse_sensitivity=0.002
    )

    # Показываем загрузку и кэшируем модели
    engine.prepare_models(screen)

    # Добавляем спрайт дерева
    tree_texture = load_image('tree', 'textures/tree.png', size=(64,64), default_color=(0,255,0))
    tree = Sprite(x=3.5*64, y=2.5*64, texture=tree_texture)
    engine.add_sprite(tree)

    running = True
    while running:
        dt = clock.tick(60) / 1000.0
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            engine.handle_event(event)
            engine.handle_mouse(event)

        keys = pygame.key.get_pressed()
        engine.update(dt, keys)
        engine.render(screen)
        pygame.display.flip()

    pygame.quit()

if __name__ == "__main__":
    main()

❓ Часто задаваемые вопросы (FAQ)

  • Модель .obj не отображается? – установите trimesh, проверьте путь и масштаб. Удалите папку cache/ для перегенерации спрайтов.
  • Повороты rotX/rotY/rotZ не работают? – используйте ключи в нижнем регистре: rotx, roty, rotz. После изменения параметров удалите кэш.
  • Видео не проигрывается? – установите imageio-ffmpeg, проверьте путь.
  • Как сделать невидимую стену? – используйте isvisible:0 или ID=2 (если нужна невидимость без коллизии).
  • Почему alpha не работает? – альфа-канал вызывает сильные лаги, поэтому он отключён. Используйте isvisible:0.
  • Как сделать скример? – триггер (ID=8) + оверлей + звук.
  • Почему триггер срабатывает каждый кадр? – используйте deactivate_trigger.
  • Упал FPS при height<1? – используйте height с осторожностью, это ресурсоёмко.
  • Как добавить свою текстуру? – положите изображение в папку textures/ и укажите путь в теге texture или используйте load_image для спрайтов.
  • Как включить полноэкранные эффекты? – используйте engine.api.set_effect('vhs', alpha=180, intensity=0.7). Подробнее в разделе Эффекты.
  • Как использовать 3D-звук? – см. раздел Звук и Sound3D.
  • Что такое .gbj? – OBJ с поддержкой цвета граней, см. Формат .gbj. Чтобы сделать модель такого формата вы можете использовать редактор объектов из архива gradus-rc.zip (redactor.py)
